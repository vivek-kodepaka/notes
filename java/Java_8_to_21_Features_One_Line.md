# Java Features -- One-Line Interview Revision (Java 8 → 21)

## Java 8

-   Lambda Expressions -- Enable functional programming by passing
    behavior as parameters.
-   Stream API -- Provides declarative processing of collections with
    map, filter, reduce.
-   Functional Interfaces -- Interfaces with a single abstract method
    used in lambdas.
-   Default Methods -- Allow method implementation inside interfaces.
-   Optional Class -- Helps avoid NullPointerException by representing
    optional values.
-   Method References -- Short syntax to call existing methods using
    `::`.
-   Date and Time API -- Modern immutable API replacing `Date` and
    `Calendar`.
-   Collectors -- Utility class to transform stream results.

## Java 9

-   Module System (JPMS) -- Enables modular applications using
    `module-info.java`.
-   JShell -- Interactive REPL tool to run Java code quickly.
-   Private Methods in Interfaces -- Allows code reuse inside interface
    default methods.
-   Stream API Enhancements -- Added `takeWhile`, `dropWhile`,
    `iterate`.

## Java 10

-   var Keyword -- Enables local variable type inference.

## Java 11 (LTS)

-   HTTP Client API -- Modern replacement for HttpURLConnection.
-   String Methods -- Added `isBlank()`, `lines()`, `strip()`.
-   Files Methods -- Added easier file reading utilities.

## Java 12

-   Switch Expressions (Preview) -- Switch can return values.

## Java 13

-   Text Blocks (Preview) -- Multi-line string literals using `"""`.

## Java 14

-   Switch Expressions (Standard) -- Switch with `yield` and cleaner
    syntax.
-   Records (Preview) -- Compact syntax for immutable data classes.
-   Helpful NullPointerException -- Better debugging messages.

## Java 15

-   Text Blocks (Standard) -- Official support for multi-line strings.
-   Sealed Classes (Preview) -- Restrict which classes can extend a
    class.

## Java 16

-   Records (Standard) -- Immutable data carrier classes with minimal
    code.
-   Pattern Matching for instanceof -- Eliminates explicit casting.

## Java 17 (LTS)

-   Sealed Classes (Standard) -- Control inheritance hierarchy.
-   Pattern Matching Improvements -- Cleaner conditional logic.
-   New Random Generator API -- Improved random number support.

## Java 18

-   Simple Web Server -- Lightweight HTTP server for testing and demos.

## Java 19

-   Virtual Threads (Preview) -- Lightweight threads for high
    concurrency.
-   Structured Concurrency (Incubator) -- Simplifies multi-threaded task
    management.

## Java 20

-   Scoped Values (Preview) -- Immutable thread-local alternative.
-   Pattern Matching for Switch (Preview) -- Switch supports type
    patterns.

## Java 21 (LTS)

-   Virtual Threads (Standard) -- Massive concurrency with low memory
    usage.
-   Sequenced Collections -- Uniform APIs for ordered collections.
-   Pattern Matching for Switch (Standard) -- Cleaner and safer switch
    logic.
-   Record Patterns -- Deconstruct objects in pattern matching.
-   String Templates (Preview) -- Safer string interpolation.

## Quick Interview Summary

-   Java 8 → Streams, Lambdas\
-   Java 11 → HTTP Client, String APIs\
-   Java 17 → Sealed classes, Pattern matching\
-   Java 21 → Virtual Threads
